# Snake Battle — MANUAL

> ภาษา: **ไทย** · [English](MANUAL.en.md) · [日本語](MANUAL.ja.md)

เกมงูบนเครื่องเดียว เขียนด้วย `turtle` ล้วน (ไม่ใช้ pygame ในการวาด) มี 2 โหมด:
**1 Player** และ **2 Player Battle** เลือกตัวละครและ power ก่อนเริ่มแมตช์

จุดเริ่มคือ **`main.py`** เท่านั้น

---

## 1. ติดตั้ง & รัน

**ต้องมี**

- Python 3.8+ ที่มี `tkinter` (turtle ใช้ tkinter ข้างใน)
  - Windows / macOS: installer ของ python.org มีมาให้แล้ว
  - Ubuntu / Debian: `sudo apt install python3-tk`
- **ไม่ต้องลงอะไรเพิ่มเลย** — เกมใช้ `turtle` + standard library เท่านั้น
  รูป `assets/*.gif` มาพร้อม repo แล้ว
- ของเสริม (ไม่จำเป็น)
  - `pip install pillow` — เฉพาะตอนจะ generate รูปใหม่ด้วย `make_sprites.py` (เช่นเพิ่มตัวละคร)

> **ไม่ต้องใช้ pygame** ทั้งภาพและเสียงทำงานบน turtle + stdlib ได้ครบ (เรื่องเสียงดูข้อ 6)

**รัน**

```bash
python main.py            # เล่นเกม
python make_sprites.py    # gen รูป GIF ใหม่ทั้งชุด (ต้องมี Pillow)
```

ตอนเปิดเกมจะพิมพ์สถานะเสียง 1 บรรทัด เช่น `SOUND: 9 events via winsound`
หรือบอกว่าทำไมยังไม่มีเสียงและต้องทำอะไร

## 3. ปุ่ม

**เมนูหลัก** — คลิกปุ่ม หรือกด `1` / `2`

**หน้าเลือกตัวละคร** — การ์ดใหญ่ 1 ใบต่อผู้เล่น มีลูกศร **◀ ▶** ข้างบนสำหรับพลิกดูตัวละคร
(คลิกที่ตัวการ์ดก็พลิกไปข้างหน้าได้) ไอคอน power คลิกได้ทั้งกล่อง จุดใต้การ์ดบอกว่าอยู่ตัวที่เท่าไหร่
หรือใช้คีย์บอร์ด

| | เลือกตัวละคร | เลือก power |
|---|---|---|
| P1 | `A` / `D` | `W` / `S` |
| P2 | `←` / `→` | `↑` / `↓` |

`Enter` เริ่มเกม · `Esc` กลับเมนู

**ในเกม**

| | 1 Player | 2 Player |
|---|---|---|
| เดิน | ลูกศร | P1 `W A S D` · P2 ลูกศร |
| ใช้ power | `SPACE` | P1 `Q` (หรือ `E`) · P2 `O` (หรือ `P`) |
| เปิด/ปิดเสียง | `X` | `X` |
| เริ่มใหม่ | `R` (ตอนตาย) | `R` (ที่หน้า Result) |
| กลับเมนู | `M` | `M` |

> **power ใช้ปุ่มเดียวต่อผู้เล่น** ไม่ว่าจะเลือก power อะไร เพราะแต่ละคนเลือกได้ 1 อย่าง
> ระบบจึงเพิ่ม power ได้เรื่อยๆ โดยไม่ต้องหาปุ่มใหม่

## 4. ตัวละคร (4 ตัว)

| ตัว | สี |
|---|---|
| AQUA | ฟ้า |
| EMBER | ส้ม |
| VENOM | เขียว |
| ROYAL | ม่วง |

**ทุกตัวเล่นเหมือนกันเป๊ะ** ต่างแค่สี — ไม่มีตัวไหนแข็งหรือเร็วกว่า ตัวละครคือ skin
และในโหมด 2P คือวิธีแยกว่างูตัวไหนของใคร ด้วยเหตุนี้ **สองคนเลือกตัวเดียวกันไม่ได้** —
ลูกศรจะข้ามตัวที่อีกฝ่ายถืออยู่ให้อัตโนมัติ (แต่ power เลือกซ้ำกันได้)

**เพิ่มตัวละคร** — เพิ่ม entry ใน `characters.py` แล้วรัน `python make_sprites.py`
หน้าเลือกตัวอ่านจำนวนจาก registry เอง (จุดบอกตำแหน่งเพิ่มตาม) ไม่ต้องแก้โค้ด UI

อยากอัพรูป `.gif` เองแทนการ gen — ดูข้อ 9

> รูป portrait บนการ์ดวาดด้วย turtle ล้วน (compound shape ย้อมสีตามตัวละคร) ไม่ได้ gen ไฟล์รูป
> และใช้ `.gif` ของ sprite แทนไม่ได้ เพราะ **turtle ย่อขยาย image shape ไม่ได้** —
> หัวขนาด 20x20 ก็จะอยู่ 20x20 ตลอดไม่ว่าจะสั่ง `shapesize()` เท่าไหร่

## 5. Power (5 อย่าง)

| Power | ผล | ค่าใช้ | ระยะเวลา |
|---|---|---|---|
| **SPEED** | เร็วขึ้น 2 เท่า | 50 | 180 เฟรม |
| **STEALTH** | ลำตัวหาย หัวเป็นเงา (**ยังชนได้**) | 50 | 180 เฟรม |
| **SHIELD** | ไม่รับดาเมจเลย | 50 | 150 เฟรม |
| **PHASE** | ทะลุกล่องและหางตัวเองได้ | 50 | 150 เฟรม |
| **FEAST** | ผลไม้ได้คะแนน 2 เท่า | 40 | 240 เฟรม |

หลอด power เต็มที่ 100 กินผลไม้ได้ +25 (2P) / +20 (1P) · กด power ซ้ำระหว่างที่ยังทำงานไม่ได้

**เพิ่ม power** — `powers.py` เขียน effect เป็น "ชนิดของผล" ที่เกมรู้จักอยู่แล้ว:

```python
speed_mult   float   คูณความเร็วหัว
score_mult   float   คูณคะแนนผลไม้
cloak        bool    ซ่อนลำตัว สลับหัวเป็นเงา
invincible   bool    ไม่รับดาเมจ
noclip       bool    กล่องและลำตัวตัวเองไม่ทำอันตราย
```

ถ้า power ใหม่ใช้ชนิดที่มีอยู่แล้ว → **เพิ่ม entry กับไอคอน จบ ไม่ต้องแก้โค้ดเกมเลย**
ถ้าต้องการผลแบบใหม่ → เพิ่ม key ตรงนี้ แล้วอ่านค่าด้วย `powers.flag()` / `powers.effect()`
ที่จุดเดียวที่ควรสนใจผลนั้น ไม่มีที่ไหนในเกม hardcode ชื่อ power

## 6. เสียง

**ไม่มีการ generate ไฟล์เสียง และไม่ต้องลง package อะไร** `audio.py` มองหาไฟล์ที่มีอยู่
ถ้าไม่เจอเลยก็เงียบและเกมเล่นได้ปกติ

### วิธีทำให้มีเสียง

เอาไฟล์ **`.wav`** ไปวางที่ `assets/sounds/` ตั้งชื่อตาม event:

```
eat.wav   hit.wav   bump.wav   power.wav   score.wav
win.wav   lose.wav  select.wav  start.wav
```

บน Windows เล่นผ่าน **`winsound`** ซึ่งอยู่ใน standard library — **ไม่ต้องลงอะไรเลย**

repo มี `sound_effect/*.mp3` อยู่แล้ว แปลงเป็น `.wav` ด้วยอะไรก็ได้ (Audacity, ffmpeg,
เว็บแปลงไฟล์) แล้ววางตามชื่อข้างบน — ทางนี้สั้นที่สุด เพราะ **`.mp3` เล่นไม่ได้** ด้วย
`winsound` หรือ CLI player มีแต่ pygame ที่อ่าน mp3 ได้ และ pygame เป็นของเสริมล้วนๆ
ถ้าไม่ได้ลง ไฟล์ mp3 จะถูกข้ามไปเลย (ไม่เล่นครึ่งๆ กลางๆ) แล้วบรรทัดสถานะตอนเปิดเกมจะบอกให้

ลำดับการค้นหาต่อ 1 event เอาอันแรกที่เจอ:

1. `assets/sounds/<event>.wav`
2. `sound_effect/<ไฟล์>.mp3` ← ใช้ได้เฉพาะเมื่อมี pygame

### backend

เลือกอันแรกที่ใช้ได้:

| backend | ต้องลง | .mp3 | เล่นทับกัน |
|---|---|---|---|
| `winsound` (Windows stdlib) | **ไม่ต้อง** ← ทางหลัก | ไม่ได้ | ไม่ได้ |
| command line (afplay/paplay/aplay/ffplay) | ไม่ต้อง | ไม่ได้ | – |
| `pygame.mixer` | ต้องลง (ของเสริม) | ได้ | ได้ |
| silent | – | – | ไม่เจอไฟล์ที่ใช้ได้ |

กด `X` ในเกมเพื่อเปิด/ปิดเสียง · ตอนเปิดเกมจะพิมพ์สถานะเสียง 1 บรรทัด

## 7. กติกา

**ผลไม้** → +100 คะแนน (×2 ถ้า FEAST), ตัวยาวขึ้น 1 ท่อน, หลอด power เพิ่ม
2P มีผลไม้ 2 ลูกในสนาม และวางห่างกันอย่างน้อย 40 px

**ชนกำแพงนอก / กล่อง** → สตัน 30 เฟรม, ทิศรีเซ็ตเป็นหยุด, ตำแหน่งไม่ถูกยืนยัน (ไม่เสียเลือด)
PHASE ทะลุกล่องได้ แต่**กำแพงนอกหยุดทุกกรณี**

**ชนลำตัวตัวเอง** → **สตันเท่านั้น ไม่เสียเลือด** (ข้าม 2 ท่อนหลังหัว) และมีช่วงกันชนซ้ำ 70 เฟรม
เพื่อไม่ให้ค้าง — งูจะไถลออกจากขดตัวเองได้เองโดยไม่ต้องกดปุ่ม

**การต่อสู้ (2P)** ตรวจทั้งสองทางทุกเฟรม:

| หัวของ A ชน | ผล |
|---|---|
| **หัว** ของ B | B เสีย 1 HP, คะแนน B ×0.5 (และเพราะตรวจสองทาง A ก็เสียด้วย) |
| **หาง** ของ B (ท่อนสุดท้าย) | B เสีย 1 HP, คะแนน B ×0.5 |
| **ลำตัว** ของ B (ท่อนกลาง) | **A เสีย 1 HP เอง**, คะแนน A ×0.5 |

หลังเสียเลือดมี immunity 60 เฟรม (sprite กะพริบ) กันโดนรัวๆ · SHIELD กันดาเมจได้ทุกแบบ

**ชนะ** → HP ศัตรูเหลือ 0 หรือทำคะแนนถึง 500 · ถึงพร้อมกันดูคะแนนสูงกว่า · เท่ากันเป็น DRAW

## 9. เปลี่ยนรูปและเสียงเอง

### 9.1 อัพรูป .gif เอง (ไม่ต้องรัน make_sprites.py)

วางไฟล์ใน `assets/` ตั้งชื่อตามนี้ **แล้วเกมหยิบไปใช้เลย ไม่ต้องแก้โค้ด**
(`<key>` คือ `p1` `p2` `p3` `p4` ตาม `characters.py`)

| ไฟล์ | ขนาดที่ใช้อยู่ | หมายเหตุ |
|---|---|---|
| `<key>_head_up.gif` `_down` `_left` `_right` | 20×20 | **ต้องมี 4 ทิศ** |
| `<key>_head_up_ghost.gif` (+ อีก 3 ทิศ) | 20×20 | หัวตอนใช้ CLOAK |
| `<key>_body.gif` | 16×16 | 1 ท่อน ใช้ stamp ซ้ำ |
| `heart_full.gif` / `heart_empty.gif` | 18×18 | หัวใจ HP |
| `fruit.gif` | 16×16 | ผลไม้ |

**กฎที่ต้องรู้ (เป็นข้อจำกัดของ turtle ไม่ใช่ของเกม)**

- ต้องเป็น **GIF** — วาง `.png` ก็ได้ `load_shape()` จะแปลงเป็น `.gif` ให้ครั้งเดียว (ต้องมี Pillow)
- **turtle หมุนรูปไม่ได้** → หัวจึงต้องมี 4 ไฟล์แยกทิศ
- **turtle ย่อขยายรูปไม่ได้** → **ขนาดพิกเซลของไฟล์ = ขนาดในเกม** สั่ง `shapesize()` ไปก็ไม่มีผล
  อยากได้งูตัวใหญ่ขึ้นต้องทำไฟล์ใหญ่ขึ้น
- ความโปร่งใสของ GIF เป็นแบบ **เปิด/ปิด** ไม่มีขอบนุ่ม
- ไฟล์ไหนหายหรือเสีย เกมไม่ล้ม — จะกลับไปใช้สี่เหลี่ยมสีให้ส่วนนั้น
- ตั้ง `USE_SPRITES = False` ใน `game_config.py` เพื่อบังคับใช้สี่เหลี่ยมสีทั้งหมด

### 9.2 ปรับสีลำตัวเองได้ไหม — ได้ แต่ต้องไม่ใส่ body gif

**turtle ทาสีทับรูปไม่ได้** ไฟล์ `.gif` เป็น Tk image item คำสั่ง `color()` ไม่มีผลกับมันเลย
ดังนั้นถ้าใส่ `<key>_body.gif` สีลำตัวจะ**ติดมากับไฟล์** แก้จาก `characters.py` ไม่ได้

หัวกับลำตัวจึงถูก**แยกการตัดสินใจออกจากกัน** เลือกได้ 4 แบบ:

| ใส่ head gif | ใส่ body gif | ผลที่ได้ |
|---|---|---|
| ✅ | ✅ | หัวและลำตัวเป็นรูปที่อัพ — สีอยู่ในไฟล์ทั้งคู่ |
| ✅ | ❌ | **หัวเป็นรูปที่อัพ ลำตัวเป็นสี่เหลี่ยมสีจาก `characters.py`** ← ตอบคำถามนี้ |
| ❌ | ✅ | ลำตัวเป็นรูป หัวเป็นสี่เหลี่ยมสี |
| ❌ | ❌ | สี่เหลี่ยมสีทั้งตัว |

> **สรุป** — อยากอัพรูปหัวสวยๆ แต่ยังคุมสีลำตัวจากโค้ดได้: **อัพแค่ `<key>_head_*.gif`
> แล้วไม่ต้องมี `<key>_body.gif`** ลำตัวจะใช้ค่า `main` ของตัวละครนั้น เปลี่ยนสีที่
> `characters.py` ได้ทันทีโดยไม่ต้องแตะไฟล์รูป

ทดสอบทั้ง 4 แบบแล้วว่าเรนเดอร์ออกจริงและไม่ error

> เกร็ด: `<key>_body_ghost.gif` **ยังไม่ถูกใช้เลย** เพราะตอน CLOAK เกมซ่อนลำตัวทั้งหมด
> ไม่ได้เปลี่ยนเป็นลำตัวเงา — ไม่ต้องเสียเวลาทำไฟล์นี้ (เว้นแต่จะแก้ให้ CLOAK โชว์ลำตัวเงาแทน)

### 9.3 ใส่เสียงเอง

**ได้เลย และไม่ต้องลงอะไร** วาง **`.wav`** ใน `assets/sounds/` ตั้งชื่อตาม event:

```
eat.wav   hit.wav   bump.wav   power.wav   score.wav
win.wav   lose.wav  select.wav  start.wav
```

ใส่แค่บางไฟล์ก็ได้ — event ที่ไม่มีไฟล์จะเงียบไปเฉยๆ ไม่ error
แปลง `sound_effect/*.mp3` ที่มีอยู่เป็น `.wav` ได้ด้วย Audacity / ffmpeg / เว็บแปลงไฟล์
(รายละเอียดข้อ 6)

## 10. หมายเหตุเชิงเทคนิค (turtle มีกับดักเยอะ)

สิ่งที่เคยทำให้เจ็บตัวมาแล้ว เก็บไว้กันพลาดซ้ำ:

- **shape หมุน 90°** — turtle หมุน shape ตาม `heading - 90` เพราะ built-in shape เขียนแบบหัวชี้ขึ้น
  shape ใน `ui_helpers.py` เขียนแบบพิกัดจอ จึงต้องแสดงผ่าน `shape_turtle()` ที่ตั้ง heading 90 ให้
- **shape turtle ทับตัวหนังสือเสมอ** — turtle เรียก `tag_raise` ทุกเฟรม อะไรที่ต้องมีข้อความทับ
  ให้วาดด้วยปากกา (`filled_rect`) แล้วรับคลิกด้วย `wn.onscreenclick` + `inside_rect`
- **`onclick()` ใช้กับ compound shape หลายชิ้นไม่ได้** — `turtle.turtle._item` เป็น list
  `tag_bind` จึงไม่ match ให้ hit-test พิกัดเองแทน
- **ต้องล้าง turtle ตอนเปลี่ยนซีน** — `hideturtle()` ไม่พอ ต้องลบ canvas item (`items`,
  `drawingLineItem`, `_fillitem`, และ cursor ที่เป็น list ถ้าเป็น compound) แล้วถอดออกจาก
  `wn._turtles` ด้วย ไม่งั้นรั่วสะสมทุกครั้งที่สลับซีน — `scene_manager.clear_all_turtles()` ทำให้แล้ว
- **image shape เป็น GIF เท่านั้น** และหมุน/ย่อขยายไม่ได้ → หัวงูต้องมี 4 ไฟล์ต่อทิศ
  และ **ทาสีทับไม่ได้** (`color()` ไม่มีผลกับ Tk image item) สีจึงติดมากับไฟล์ — ดูข้อ 9.2
- **การวางท่อนลำตัว** เดินย้อน path สะสมระยะทาง ไม่ใช่นับเฟรม ไม่งั้นตอน SPEED ลำตัวจะยืดห่าง
